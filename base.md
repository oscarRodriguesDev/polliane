# Base de inspiração da Pollianne

> Coloque aqui os links que a Pollianne deve consultar para se inspirar na hora de responder.
> Pode ser: posts, perfis, conversas, histórias, qualquer coisa que capture o jeito dela.
> Um link por linha. Comentários com `#` são ignorados.
> O bot lê o conteúdo real de cada link e usa como referência de tom, vocabulário, opiniões e assuntos.

# Exemplos (troque pelos seus links):

# https://exemplo.com/como-a-pollianne-fala
# https://exemplo.com/historias-que-ela-gosta
